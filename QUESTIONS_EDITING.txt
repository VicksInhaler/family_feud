RETRO FAMILY FEUD — HOW TO EDIT QUESTIONS

Edit this file in Notepad:
  questions.js

Do NOT edit index.html just to change questions or answers.

Each question looks like this:

 {cat:'Retro Gadgets',
  q:'Name a gadget people commonly used before smartphones became popular.',
  a:[
    ['Game and Watch',30],
    ['Game Boy',24],
    ['Walkman / Discman',19],
    ['Family Computer / Atari',15],
    ['Pager / Beeper',12]
  ],
  notes:'Accepted alternatives / host notes here.'},

RULES / TIPS
1. cat = category shown to the host/audience.
2. q = question text.
3. a = answer list. Each item is ['Answer', points].
4. notes = host notes / accepted alternatives.
5. Recommended: keep 5 answers per question for the current Family Feud layout.
6. Recommended: make the answer points total 100.
7. Keep commas, brackets, and quote marks in place.
8. Keep the Tie-Breaker as the LAST question in the file.
9. Save questions.js, then refresh/reopen index.html.
10. Keep questions.js in the SAME folder as index.html.

AUDIO
If using the external wrong-answer sound, also keep:
  wrong-answer.mp3
in the same folder as index.html.

WINNER PAGE
Keep winner.html in the same folder as index.html.

PRELIMINARY QUESTIONS
Edit preliminary-questions.js to change the one-answer questions shown before category selection.
Each entry uses q for the question and a for its answer. The seven questions cycle in order.
In the host panel, reveal the answer, then click Correct - Pick Category to unlock the cards.
Selecting a category consumes the unlock and advances to the next preliminary question.
Preliminary questions do not add points. Progress is saved, supports Undo, and clears on Reset Entire Game.
QUICK FIRE LANDING
Each Quick Fire starts with the Retro Family Feud logo. Use Show Question, then Reveal Answer, then Correct - Pick Category in the host panel.
Use Quick Fire Landing to return to the logo and hide the current question/answer.

ONE PICK PER CATEGORY
Picked categories stay disabled, including after Undo or refreshing the windows. Only Reset Entire Game makes them available again.
