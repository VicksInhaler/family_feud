RETRO FAMILY FEUD — BLAST FROM THE PAST
Updated game package

HOW TO RUN
1. Open index.html in a modern desktop browser (Chrome, Edge, Firefox, or Safari).
2. For a projector setup, click "Open Audience Window".
3. Move the audience window to the projector/second display and use Full Screen.
4. Keep the main window on the host laptop for answer reveals, strikes, scoring, undo, and round selection.

UPDATED CONTENT
- 12 selectable main questions plus 1 tie-breaker.
- Added "80s–90s Date Venues": Cinema/Movie Theater, Disco/Dance Club, Zoo, Museum, Library.
- Added "Geek Throwback": COBOL, Pascal, FORTRAN, BASIC, Ada.
- All answer-board scores are simulated survey scores for entertainment, not actual survey data.

UPDATED EFFECTS
- Correct-answer sound is now a longer multi-note chime.
- Wrong-answer buzzer is now longer and more dramatic.
- Winner dashboard includes a multi-second neon confetti celebration.
- Winner celebration is also sent to the separate audience window when it is open.

HOST SHORTCUTS
- 1–5: Reveal/hide an answer
- X: Add strike
- Left/Right Arrow: Previous/next question
- H: Toggle host/audience view

The game runs locally and does not require an internet connection or external account.
